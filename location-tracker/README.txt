LOCATION TRACKER DEMO - TUGAS KULIAH

1. Pastikan Node.js sudah terpasang.
2. Buka CMD di folder proyek.
3. Jalankan:
   npm install
4. Jalankan:
   npm start
5. Buka halaman demo:
   http://localhost:3000/
6. Dashboard:
   http://localhost:3000/dashboard.html

CATATAN:
- Lokasi GPS hanya diperoleh melalui izin resmi browser.
- Jika pengguna menolak izin, lokasi tidak dikirim.
- Informasi perangkat/baterai bergantung pada kemampuan browser.
- Untuk akses GPS dari HP melalui internet, deployment harus menggunakan HTTPS.
